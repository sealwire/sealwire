# `/goal`

[English](goal.md)

给这个会话一条终点线，让它自己一直干，直到抵达。它只会为三件事停下来：**干完了**（以及它凭什么这么说）、**卡住了**（以及原因），或**需要你拍板**。

```text
/goal  让手机上的设置页和电脑上的一样好用
/goal  让 crates/relay-server 里的测试全部通过，一个都不许跳过
/goal
```

只敲 `/goal`、后面什么都不写，就是停掉正在跑的目标。

**MCP：** 智能体靠 Sealwire 的 MCP 工具推进目标，但它自己不能设定或修改目标——只有你能。见[下文](#mcp)。

## 适合用来

- 终点明确、要跑很多轮的活：把测试跑绿、移植一个功能、把一个 bug 追到根上。
- 你走开的时候让它接着跑。回来看到的是*干完了*、*卡住了*，或一个问题——而不是一个干到一半停下来问"要不要继续？"的智能体。

只问一个问题、或者改一小处，用不着它：直接发消息就行。

## 怎么运作

1. 你设定目标。还是这个会话接着干，不会新开智能体。
2. 智能体列出计划（最多 12 步），做完一步勾一步。计划显示在目标的那张框里。
3. 智能体每干完一轮、但没结束目标，Sealwire 就再给它一轮让它接着干。用普通文字说"我干完了"并不会结束目标。
4. 以下情况会结束：智能体报告干完了、卡住了或要问你；你把它停掉；或者跑满 20 轮。

*干完了* 只是智能体的说法，不是定论。它会附上做了什么、还剩什么要你处理。点 **Mark done** 表示认可；点 **Not done — keep going** 让它回去接着干。目标卡住或在等你时，你回一句话它就会重新动起来。

智能体如果在等它用 `delegate` 找来的另一个智能体，目标会先暂停，不去催它。

## 前提条件

- **Full access (YOLO)。** 目标是让会话自己跑、没人盯着，所以它得能不问人就动手。不是的话 `/goal` 会被拒绝，并提示你切过去。
- 是你自己的普通会话——不是任务里的、不是 Orchestrator，也没有被别的东西（审阅、其他驱动方）占着。
- 目标不超过 8000 个字符。

## MCP

这是唯一一条要靠 MCP 才能跑起来的命令。智能体用 Sealwire 的工具来完成它那部分：

| 工具 | 智能体拿它做什么 |
|---|---|
| `goal_status` | 读目标和目前的计划 |
| `goal_plan` | 列出步骤 |
| `goal_step` | 把某一步标成进行中或已完成 |
| `goal_complete` | 报告干完了，附上证据和还剩什么要你处理 |
| `goal_blocked` | 报告做不到，以及原因 |
| `goal_needs_you` | 问你一个问题，可以带几个选项 |

它*做不到*的是写目标。没有任何工具能设定或修改目标——智能体要是能改自己的目标，就会把它改成一个自己做得完的。这些工具同样需要 Full access；权限受限的会话一调用，就会被告知去请你切换。

Sealwire 支持的每家 provider——Claude Code、Codex、Cursor、OpenCode、Pi——都有这些工具。

## 和另外几条比

- [`/delegate`](delegate.zh-CN.md) 和 [`/handover`](handover.zh-CN.md) 会请来另一个智能体。`/goal` 让你正在对话的这个一直干下去。
- 目标里可以用到别的命令：智能体朝目标干的过程中，可以用 `delegate` 工具把支线活交出去。那些答案会算进 20 轮里。
